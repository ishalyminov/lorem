# Lorem – Location Reminders

Lorem helps you set location-based reminders that trigger when you arrive at or leave a chosen place.

## Features

- Set reminders tied to real-world locations
- Choose a proximity radius (50m, 100m, 200m)
- Search for places or tap the map to pick a location
- Import and export your reminders as JSON
- Runs in the background with minimal battery use
- Clean, modern UI with animated gradient backgrounds

## Short Description

Location-based reminders that notify you when you're near a saved place.

## Full Description

Lorem is a lightweight location reminder app. Set a reminder for any place — your grocery store, the gym, or a friend's house — and get notified when you're nearby.

• Pick locations on the map or search by address
• Set your preferred proximity radius (50m, 100m, or 200m)
• Edit or delete reminders with a swipe
• Export and import your reminders for backup or sharing
• Works in the background — no need to keep the app open

Built with privacy in mind: no accounts, no cloud, no tracking. Your data stays on your device.
